# Dataset Information

The raw dataset used in this project is not included in the GitHub repository because of its size and redistribution considerations.

## Expected File

To reproduce the analysis, place the dataset in this folder using the filename:

```text
recipes.csv
```

Save the file.

Your structure will then look like:

```text
cuisine-classification/
├── README.md
├── .gitignore
├── data/
│   ├── README.md
│   └── recipes.csv   ← local only, ignored by Git
├── images/
├── notebooks/
│   └── cuisine_classification.ipynb
└── docs/
```
